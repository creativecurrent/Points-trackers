Team Points Tracker

A web application that allows users to track points for team members and save/load data using their email address.
Features

✔️ Add/Remove Points (+1, +5, -1)
✔️ Add/Remove Team Members
✔️ Save & Load Data by Email (stored in browser's localStorage)
✔️ Responsive Design (works on desktop & mobile)
✔️ Default Team Members (EMPIRE, jeriye, Mahq, Ryan, sour)
How to Use

    Add/Modify Points

        Click +1 or +5 to add points

        Click -1 to remove points

        Click × to delete a team member

    Add New Members

        Type a name in the input field

        Click "Add Member"

    Save/Load Data

        Enter your email in the input field

        Click "Save Data" to store your points

        Click "Load Data" to retrieve saved data
